# Hai-gaon-vue

אתר לספר סדר פתרון חלומות מהרב הגאון רבינו האי ז"ל ויוסף הצדיק ודניאל איש חמודות ורש"י ז"ל וחכמים אחרים , ניתן להפצה חופשית לזיכוי רבים .

### Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```
